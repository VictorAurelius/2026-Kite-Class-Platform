## Troubleshooting Guide

### If Tests Fail

#### Unit Tests Fail
```bash
# Run locally to diagnose
cd kiteclass/kiteclass-core
./mvnw test -Dtest=FailedTestClass

# Check logs
cat target/surefire-reports/FailedTestClass.txt

# Fix and re-commit
git add .
git commit --amend
git push --force-with-lease
```

#### Integration Tests Fail
```bash
# Run with Docker locally
docker-compose up -d postgres redis
./mvnw test

# Check Testcontainers logs
./mvnw test -Dlogging.level.org.testcontainers=DEBUG
```

### If Build Fails
```bash
# Check compilation locally
./mvnw clean compile

# Review error logs
./mvnw clean package -X | grep ERROR
```

### If Security Scan Fails
```bash
# Run Trivy locally
docker run --rm -v $(pwd):/workspace aquasecurity/trivy fs /workspace

# Review and fix vulnerabilities
./mvnw versions:display-dependency-updates
```

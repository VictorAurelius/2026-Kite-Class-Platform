### Category 3 — Primitive Obsession (14/20)

Detector tightening on entity fields revealed real domain Primitive Obsession:

```
Student.java:
  private String email;
  private String phone;
```

**Acceptable (boundary DTOs, per scoring-guide exclusion):**
- `marketing/dto/response/LeadResponse.java` — JSON translation
- `marketing/dto/response/ContactMessageResponse.java`
- `marketing/dto/request/UpdateLeadRequest.java` (already has `@Size` validation)
- `invoice/dto/*` BigDecimal fields — accepted at boundary

**Real hotspot:** Student entity (`kiteclass-core/.../module/student/entity/Student.java`) holds email + phone as primitives. Per `ai-branding-guidelines.md` watch list: should be `Email` + `Phone` value objects.

**Note:** This is NOT in current GAP-046 scope. Surface as new gap candidate (low-priority, defer until value-object library exists OR file as P3 cleanup).

### Category 4 — Leaky Abstraction (16/20)

```
kitehub-branding/.../client/OllamaClient.java          ← architectural choice
kitehub-branding/.../config/AIProviderConfig.java      ← false+ (config bean wiring)
```

**Calibration question:** `OllamaClient` IS isolating Ollama types within the `client/` package — same role as an Adapter, just different naming convention. Two options:
1. **Rename** `client/` → `adapter/` to match `mcp-first-with-fallback.md` + `design-patterns.md` Mandatory Patterns matrix terminology
2. **Adjust detector** exclude pattern to include `/client/` packages alongside `/adapter/`

Option 1 is cleaner architecturally; Option 2 acknowledges the shipping codebase convention. Defer to wave closure decision; not blocking.

```
kiteclass-core/.../common/config/RabbitConfig.java                ← false+ (javadoc comment)
kiteclass-core/.../module/branding/events/BrandingEventPublisher  ← intentional fast-path
kiteclass-core/.../module/parent/.../ParentInvitationServiceImpl  ← real hotspot
kitehub-branding/.../service/BrandingJobService.java              ← real hotspot

kitehub-subscription/.../client/EmailServiceClient.java           ← real hotspot
kitehub-subscription/.../service/InstancePurgeService.java        ← real hotspot
```

**Mitigating context for BrandingEventPublisher:**
> ```java
> // Best-effort fast-path for cache eviction; outbox is the reliability net.
> if (rabbitTemplate != null) { ... rabbitTemplate.convertAndSend(...) ... }
> ```
> Documented intentional bypass — fast-path for cache invalidation latency, with outbox covering reliability. Acceptable under documented exception policy.

**Real hotspots: 5 services** publish directly to RabbitMQ without Outbox. No centralized policy on when bypass is acceptable. **NEW GAP candidate** — tracked as **GAP-222** (this PR).

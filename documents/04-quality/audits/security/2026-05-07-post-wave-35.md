### P1 — 3 findings

**P1-1: K8s deployments thiếu `securityContext.runAsNonRoot`**
- File: `infrastructure/k8s/kiteclass-template/gateway-deployment.yaml`, `infrastructure/k8s/kitehub/branding-deployment.yaml` (toàn bộ deployments)
- Evidence: `grep runAsNonRoot|securityContext infrastructure/` → 0 matches
- Risk: container escape → host root nếu compromised
- Fix effort: 1h (add `securityContext: { runAsNonRoot: true, runAsUser: 1000 }` per pod template)
- Đề xuất gap: GAP-XXX-k8s-security-context-missing

**P1-2: Plaintext invite token trong email href (carry-over baseline)**
- File: Thymeleaf email template (beta invite)
- Evidence: token UUID raw trong `<a th:href="${inviteUrl}">`
- Risk: PDPL không guarantee email TLS end-to-end; token interception
- Fix effort: 2h (2FA challenge) hoặc 5h (S/MIME)
- Đề xuất gap: GAP-388 (đã có trong cluster) — verify scope

**P1-3: Per-email rate-limit chưa fix (carry-over baseline)**
- File: `BetaAccessService.submitRequest()`
- Evidence: gateway rate-limit chỉ per-IP; single IP có thể spam unique emails
- Fix effort: 1h (Redis-based per-email counter)
- Đề xuất gap: GAP-388 cluster

### P2 — 3 findings

**P2-1: CSP / HSTS headers chưa explicit trong gateway**
- File: `kitehub/kitehub-gateway/src/main/resources/application-prod.yml`
- Evidence: Chỉ có CORS + DedupeResponseHeader; không có `Content-Security-Policy`, `Strict-Transport-Security`, `X-Content-Type-Options`, `X-Frame-Options`
- Fix effort: 2h (Spring Cloud Gateway response header filter)

**P2-2: AWS Secrets Manager rotation policy chưa documented**
- File: `documents/05-guides/operations/secrets-management.md` (chưa tồn tại)
- Evidence: ADR-025 AWS Singapore Free Tier nhưng rotation cadence chưa codified
- Fix effort: 2h (runbook + cadence: 90d non-prod, 30d prod)

**P2-3: CI dependency scan automation chưa wire**
- Evidence: `.github/workflows/` thiếu `pnpm audit` + `mvn dependency-check` job
- Fix effort: 1h (workflow snippet)

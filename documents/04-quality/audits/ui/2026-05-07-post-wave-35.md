## Accessibility / Responsive / i18n notes

**Accessibility (WCAG 2.1 AA):**
- ConsentBanner = exemplary: role/aria/focus-trap/ESC/live-region all present. Có thể làm reference template cho components sau.
- BetaRequestForm: honeypot có `aria-hidden="true" + tabIndex=-1` đúng.
- Admin beta table: `<th>` semantic OK, nhưng thiếu `<caption>` cho screen reader context.
- Tất cả Wave 33-35 screens dùng theme tokens → contrast pre-validated AA.

**Responsive:**
- ConsentBanner: `flex-col gap-2 sm:flex-row sm:flex-wrap sm:items-center sm:justify-end` — wrap đúng từ mobile lên desktop.
- BetaRequestForm: `space-y-5` + `w-full` inputs — single-column mobile-friendly.
- Admin beta table: `overflow-hidden` trên container nhưng không `overflow-x-auto` → mobile sẽ bị cắt cột. **W35-P2-5 thêm vào danh sách P2.**

**i18n:**
- 100% hardcoded VN. ConsentBanner có `COPY_VI` constant + comment EN copy "may land Phase 2" — design pattern tốt, dễ refactor sau.
- ConsentBanner accept `lang` prop nhưng silently fall-back vi (line 86 `void props.lang`) — should warn-or-throw thay vì silent.

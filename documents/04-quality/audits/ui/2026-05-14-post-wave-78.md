## 4. Findings

### P0 (block release)

KHÔNG có. ✅ — Wave 78 không phát sinh P0 a11y / responsive / dark-mode breakage.

### P1 (file follow-up)

**P1-A — Focus-trap + Escape key trong dialogs mới (GAP-545)**

3 dialogs mới (FeedbackWidget modal, OnboardingChecklist demo-confirm modal, BetaDisclaimer N/A vì banner) thiếu:
1. Focus trap — `Tab` sẽ exit modal → background page focusable
2. `Escape` key handler để close
3. Auto-focus trên first input khi open

Vi phạm WCAG 2.1.1 (Keyboard) + 2.4.3 (Focus Order). Beta tenant dùng keyboard-only (screen reader) sẽ không thoát modal sạch.

Mitigation hiện tại: close button có `aria-label`; `role="dialog"` + `aria-modal="true"` đúng. Nhưng SR user vẫn cần `Escape` shortcut theo WAI-ARIA APG.

### P2 (Wave 79+ batch)

**P2-A — Silent error swallow + plain-text email fallback (GAP-546)**

- `FeedbackWidget.tsx` line 122 `// ignore JSON parse error` — silent. Production debugging khó khi server trả non-JSON 500.
- Per Bucket E audit notes: 5 email templates thiếu plain-text `.txt` fallback (RFC 2049). Tracked existing GAP-543 PARTIAL. Re-flag as P2 cho cross-client compatibility.

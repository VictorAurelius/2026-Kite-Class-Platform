## Findings

### Strengths

1. **Contract-first foundation cho 4 NEW domain endpoints (Bucket 0 PR #1349)** — onboarding/feedback/beta-status/support api-contract.md đã ship TRƯỚC khi FE/BE bucket execute. Tuân thủ `contract-first-for-cross-layer.md` v1.0.1 §3 hoàn toàn (Bucket 0 Foundation pattern).
2. **Request/Response schema 1:1 với contract** trên 5 endpoints documented — `FeedbackSubmissionRequest` DTO mirror contract bảng field constraints; `OnboardingProgressResponse` mirror contract response body.
3. **Error envelope chuẩn RFC 7807 (`ProblemDetail`)** — onboarding controller `@ExceptionHandler` consistent, dùng `body.setProperty("error", "<CODE>")` để attach application error code.
4. **Public endpoints khai báo rõ** — beta-status contract ghi `Public (unauthenticated)`; feedback contract ghi `Public (unauthenticated submit allowed)`. Phân biệt rõ với auth-gated endpoints.
5. **Rate-limit documented per contract** + gateway implementation đồng bộ — feedback 10/min/IP, beta-status 60/min/IP, onboarding PUT 60/min/tenant.

### Weaknesses

1. **2FA endpoint cluster (Wave 78 NEW) chưa có api-contract.md** — GAP-547 P0 — 5 endpoints chưa documented + chưa versioned. Block pre-release `v1.0.0-rc.*` gate.
2. **`/api/auth/**` không versioned URL** — pre-existing debt từ Wave 35 auth scaffolding; Wave 78 không sửa nhưng cũng không nên thêm endpoint mới vào unversioned namespace. Sẽ cần migrate sang `/api/v1/auth/**` cùng với deprecation policy ≥6 tháng (per rubric §2.4.4).
3. **Password-reset endpoint missing BE** — GAP-548 P1 — gateway sẵn sàng nhưng controller chưa implement; defense-in-depth comment trong yml ghi nhận, nhưng end-to-end UX không khả dụng.
4. **Feedback error code mapping thiếu controller-side handler** — contract documented 6 error codes nhưng controller chưa expose custom `@ExceptionHandler` cho từng code. Spring default validation envelope hoạt động (FE thấy 400 + field message) nhưng không match enum codes contract đề xuất.
5. **Pact / CDC tests vẫn missing** — Wave 40 baseline FAIL trên Cat 5.3 không đổi. Phase 1 BETA acceptable; Phase 1.5 PAID cần ship trước launch.

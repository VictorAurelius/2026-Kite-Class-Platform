# GAP-028: AI Model Versioning & Migration Strategy

**Status:** 🔵 OPEN
**Priority:** 🟡 P2
**Domain:** AI / DevOps
**Detected:** 2026-04-14 (simulation)

## Problem

AI model ecosystem update rất nhanh (Gemma 4 ra 2026-04, Gemma 5 có thể 2026-10). Hiện tại **không có strategy** cho versioning/migration:

- ❌ Không có framework A/B test models (so sánh output quality)
- ❌ Không có rollback mechanism nếu model mới kém hơn
- ❌ Không có backward compat — outputs cũ match template version cũ
- ❌ Không có deprecation notice/timeline
- ❌ Không track "which model generated which asset"

## Proposed Fix

### 1. Model Metadata Tracking

```java
@Entity
public class BrandingResource {
  // ... existing fields ...

  String aiModelVersion;    // "gemma4:e4b-2026-04-02"
  String aiPromptVersion;    // "v2.1" — version of prompt template
  JsonObject modelParams;    // temperature, seed, etc.
}
```

Every generated asset tagged với model version → reproducibility + analytics.

### 2. Model Catalog

```yaml
# ai-model-catalog.yml
models:
  text:
    current: "gemma4:e4b"
    candidates: ["gemma4:26b-moe", "llama3.1:8b"]
    deprecated: ["gpt-4-turbo"]

  vision:
    current: "gemma4:e4b"  # multimodal native
    candidates: []
    deprecated: ["llava:13b"]

  image-gen:
    current: "sdxl-1.0"
    candidates: ["sdxl-turbo", "flux-schnell"]
```

### 3. A/B Testing Framework

```java
@Service
public class ModelABTester {
  public String selectModel(String userId, ModelCategory cat) {
    // Bucket 10% of traffic to candidate
    if (experimentBucket(userId) < 0.1) return candidate;
    return current;
  }

  public void recordOutcome(String userId, String modelId, Metrics m) {
    // Track: latency, quality score, user satisfaction
  }
}
```

### 4. Migration Playbook

Khi model mới ra:
```
Phase 1: Add to catalog as "candidate" (shadow mode, 0% traffic)
Phase 2: A/B test 10% traffic for 2 weeks
Phase 3: Analyze metrics — quality, latency, cost
Phase 4: Ramp to 50% if better, rollback if worse
Phase 5: Full rollout, mark old as "deprecated"
Phase 6: 3 months deprecation notice → remove
```

### 5. Backward Compat

- Templates có `compatibleModels: []` array
- Nếu asset generated by deprecated model → mark as "regenerate recommended"
- Tenant có thể trigger "Refresh with latest AI" batch job

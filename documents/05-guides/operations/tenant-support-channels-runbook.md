## 3. Email channel (active now)

### 3.1 Setup

- Domain: `kitehub.me` (MX → Cloudflare Email Routing → forward to admin mailbox)
- Inbound: `support@kitehub.me` → forward `admin@gmail.com` (solo-dev personal Gmail)
- Outbound: AWS SES production-ready (per GAP-370); tenant nhận email từ `noreply@kitehub.me`

### 3.2 SLA + monitoring

- **Giờ phản hồi:** 08:00 — 18:00, Thứ Hai — Thứ Bảy (Chủ nhật nghỉ Phase 1)
- **Cam kết Phase 1 BETA:** 4 giờ phản hồi đầu tiên
- **Auto-acknowledge:** template auto-reply confirm received + ticket ID

### 3.3 Email template auto-reply (suggest)

```
Chào chị/anh,

KiteHub đã nhận yêu cầu hỗ trợ của chị/anh (mã: TKT-{ticketId}).
Đội ngũ sẽ phản hồi trong vòng 4 giờ làm việc (08:00-18:00, Thứ Hai-Thứ Bảy).

Nếu yêu cầu khẩn cấp (lớp đang dạy mà hệ thống lỗi, hoá đơn sai gấp), chị/anh nhắn em qua Zalo OA:
https://zalo.me/kitehub
hoặc gọi số (sẽ cập nhật khi Zalo OA active).

Trân trọng,
Đội ngũ KiteHub
```

## 4. Zalo OA Free channel (placeholder — chờ đăng ký)

### 4.1 Lý do dùng Zalo OA Free Phase 1

- VN edu user dominant communication channel (Zalo > SMS > email cho non-formal)
- Zalo OA Free tier đủ cho < 1000 followers (đủ Phase 1 BETA 5-50 tenant)
- Faster turnaround (P2 owner kỳ vọng < 1 giờ phản hồi qua Zalo)

### 4.2 Prerequisites đăng ký Zalo OA Free

User-action prerequisites (solo-dev chuẩn bị parallel; **3-7 ngày approval window**):

- [ ] CMND/CCCD cá nhân hoặc giấy phép kinh doanh
- [ ] Domain xác thực: `kitehub.me` (đã có)
- [ ] Logo + cover image 1024×1024 PNG
- [ ] Mô tả OA 80 chữ tiếng Việt
- [ ] Số điện thoại verify Zalo
- [ ] Đăng ký tại https://oa.zalo.me/manage/register/create

### 4.3 Expected URL pattern post-approval

```
Public URL:    https://zalo.me/<oa_id>
Vanity URL:    https://zalo.me/kitehub (cần verify domain match)
QR code:       Auto-generated by Zalo OA dashboard, download PNG
```

### 4.4 Swap procedure (placeholder → real OA)

Khi Zalo OA approved (3-7 ngày sau submit):

1. **Replace placeholder URL trong codebase:**
   ```bash
   # Find all references
   grep -rn "https://zalo.me/kitehub" \
     kitehub/kitehub-frontend/src \
     kitehub/kitehub-email/src/main/resources/templates \
     documents/05-guides/operations \
     documents/05-guides/user-manual

   # Replace via Edit tool (per agent-action-bias.md — do it yourself, not user)
   ```

2. **Update env var (nếu route qua env-vars-registry):**
   ```yaml
   # kitehub/docker-compose.kitehub.yml + production secrets
   SUPPORT_ZALO_OA_URL: https://zalo.me/<real_oa_id>
   ```

3. **Update email templates:**
   - `kitehub-email/src/main/resources/templates/emails/welcome.formal.html` footer
   - `kitehub-email/src/main/resources/templates/emails/beta-invite.html` footer
   - `kitehub-email/src/main/resources/templates/emails/invoice.html` footer

4. **Update user manual:**
   - `documents/05-guides/user-manual/anonymous/*.md` support footer (if exists)

5. **Update runbook + playbook:**
   - This file §2 row 2 → flip 🟡 → ✅
   - `beta-cohort-onboarding-playbook.md` §4.3 Zalo template
   - `support-escalation-runbook.md` Tier 1 entry

6. **Smoke test:**
   - [ ] OA Public URL resolve OK
   - [ ] Send test message → coordinator receive < 10s
   - [ ] Reply from coordinator → tenant receive < 10s

7. **Announcement:**
   - Email broadcast tới 5 cohort tenant: "Zalo OA chính thức đã active — chị/anh follow [link] để nhận hỗ trợ nhanh hơn"

### 4.5 Fallback nếu Zalo OA bị từ chối

- Tier 1 (Free) bị từ chối → thử Tier 2 (Premium ~500k/tháng, instant approval)
- Cả 2 bị từ chối → tạm dùng **Zalo personal account** của coordinator (acceptable Phase 1 BETA solo-dev)
- Long-term Phase 2: chuyển sang Intercom / Crisp (international SaaS với VN support)

## 5. Phone channel (escalation only — P0 incident)

### 5.1 Status Phase 1 BETA

- **KHÔNG publish số điện thoại trên website / email footer** (tránh spam + cohort manageable)
- **Số dev cung cấp riêng** cho 5 cohort tenant đầu via Zalo (1-1 share, không broadcast)
- **Phone only P0:** Owner phone số chỉ kích hoạt khi system down > 30 phút trong giờ học

### 5.2 SLA

- **P0 (system down):** trả lời trong 30 phút (kể cả ngoài giờ 18-08; tổng tối đa 24/7 cho 5 tenant cohort)
- **P1-P2:** không dùng phone; chuyển Zalo OA / email

### 5.3 Phase 2 hardening

- Phase 2: thuê thêm 1 support agent → phone published trong giờ 08-18
- Phase 3: 24/7 hotline qua VoIP (Twilio + Asterisk; hoặc outsource VN BPO)

## 9. Failure modes

| Failure mode | Trigger | Recovery |
|---|---|---|
| **Email bounce** | DNS MX misconfig | Verify CF Email Routing rules + DNS MX TTL |
| **Zalo OA bị từ chối approval** | Domain unverified / docs thiếu | §4.5 fallback ladder |
| **Coordinator burnout (5 tenant × 3 channels)** | Phase 1 cap 5 tenant + Zalo template macros + email auto-reply | Phase 1.5 thuê 1 agent |
| **Phone spam tenant share số** | Coordinator request tenant không share số | Đổi số nếu spam vượt 5 cuộc/ngày |
| **Multiple tenant cùng lúc P0** | Cohort cap 5 + Zalo OA queue | Triage theo "lớp đang dạy" (real-time impact) > "khai báo thuế hạn cuối" (formal) |

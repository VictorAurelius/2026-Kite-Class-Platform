G4 — Class Schedule Manager

Principal sets up Lớp 6A1 weekly schedule. Vietnamese week starts Monday. Auto-overlay holidays Tết / 30/4 / 2/9.

Persona: Principal / Owner / Teacher · Used: KC /classes/[id]/schedule (route mới)

5 trạng thái

1 — Empty

Chưa có buổi học. CTA "Thêm buổi" + 3 mẫu nhanh (3 buổi/tuần / hằng ngày / cuối tuần).

2 — Single class

1 buổi đơn lẻ T4 14:00-15:30. Detail panel + CTA chuyển sang lặp lại hằng tuần.

3 — Recurring edit

Form lặp lại tuần T2/T4/T6 + live preview "168 buổi, bỏ qua 6 ngày lễ".

4 — Conflict warning

Trùng giáo viên — visual conflict block + 3 cách giải quyết.

5 — Saved

Toàn cảnh tuần với 3 môn (Toán/Văn/Anh), 3 GV, stat strip, class list.

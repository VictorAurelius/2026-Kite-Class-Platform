# KiteHub UI Kit

SaaS control-plane for center owners. Sky blue (`#0EA5E9`) primary + orange (`#F97316`) accent.

## Components
- `MarketingHeader.jsx` — sticky nav, backdrop-blur
- `Hero.jsx` — gradient hero with mock dashboard
- `FeatureCard.jsx` — tinted + decorative emoji + gradient chip
- `PricingCard.jsx` — 3 tiers with "Phổ biến nhất" ribbon
- `FAQ.jsx` — accordion with empathetic copy
- `CustomerSidebar.jsx` — dashboard shell
- `WelcomeBanner.jsx` — greeting by time-of-day
- `StatCard.jsx` — admin stat tile
- `TrungTamList.jsx` — tenant list with status pills
